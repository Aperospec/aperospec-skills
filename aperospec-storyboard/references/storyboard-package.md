# Storyboard Package Template

Use this template only when the input is a complete Narrative World Package (NWP).

## Input Gate

Confirm the NWP contains:
- WORLD
- EMOTIONAL ENVIRONMENT
- SOMETHING IS COMING
- CORE CONFLICT
- EMOTIONAL CURVE
- IMMERSIVE EXPERIENCE
- VISUAL WORLD
- SCENE POTENTIALS

If fields are missing, ask for a valid NWP from `aperospec-cinema`.

## Validation Checklist

- Output is SBP, not VDP.
- No visual design decisions appear.
- No image prompts appear.
- No typography or layout appears.
- Every storyboard beat maps to the NWP.
- Silent Slides and Emotional Peaks are explicit.
