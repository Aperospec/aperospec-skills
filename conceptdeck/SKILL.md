# ConceptDeck Narrative Engine

`概念驱动型沉浸式视觉叙事引擎`

## Core Definition
This skill translates the Narrative Universe into a concept-driven immersive Deck.

## Council Mode Rules
In Council Mode, ConceptDeck DOES NOT directly output the complete CDP.
It ONLY judges:
- page advancement
- concept sequence
- chapter structure
- information density
- emotional rhythm
- page splitting possibilities

## Production Mode Rules
Only when Runtime explicitly enters Production Mode or explicitly requests a formal CDP, does ConceptDeck output the complete Concept Deck Package (CDP).
