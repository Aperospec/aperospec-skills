# ConceptDeck Narrative and Editorial Engine

`概念驱动型沉浸式视觉叙事引擎`

## Core Definition
This skill translates the Narrative Universe into a concept-driven immersive Deck whose sequence and visible language are ready for visual direction.

ConceptDeck owns:
- page roles, sequence, rhythm, and information density;
- title system, title-to-content payoff, and Voice Contract;
- final audience-facing copy for every page;
- factual and wording locks passed through the approved Evidence Lock.

ConceptDeck does not own layout, font selection, image generation, crop execution, overflow repair, or export.

## Council Mode Rules
In Council Mode, ConceptDeck DOES NOT directly output the complete CDP.
It ONLY judges:
- page advancement
- concept sequence
- chapter structure
- information density
- emotional rhythm
- page splitting possibilities
- editorial angle and title promise
- voice and speaking distance
- page-level copy direction and information payoff

## Production Mode Rules
Only when Runtime explicitly enters Production Mode or explicitly requests a formal CDP, does ConceptDeck output the complete Concept Deck Package (CDP).

Before producing audience-facing copy, read [references/editorial-copy.md](references/editorial-copy.md). Use [references/concept-deck-package.md](references/concept-deck-package.md) for the formal CDP structure.
