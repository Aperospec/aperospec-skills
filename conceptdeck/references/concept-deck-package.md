# Concept Deck Package (CDP) Template

Use this template when Runtime requests a formal CDP from a complete Narrative World Package (NWP). Runtime may also pass only the minimum approved Evidence Lock fields and active output-channel constraints required for accurate copy.

Do not accept raw research pages, unverified claims, original project documents, visual layouts, or rendering instructions.

The CDP must hand a usable sequence and final audience-facing language to:

> `visualdirector`

without requiring VisualDirector to invent page logic, labels, titles, or supporting copy.

## Rules
- Every concept deck beat maps to the NWP.
- One concept per slide.
- One emotional state per slide.
- One atmosphere per slide.
- Forbidden: consecutive high-information slides.
- CDP must provide final page-level copy for VisualDirector to remain faithful without inventing or rewriting language.
- A short variant is an approved compression, not permission to change the promise or fact boundary.
- Important limitations must remain visible; they cannot be hidden to make layout easier.
- Do not add labels, English microcopy, issue numbers, or pseudo-editorial metadata merely to fill space.
- CDP may guide visual intent, but may not execute final poster composition.
- If accurate copy cannot be written from the permitted inputs, return the issue to Runtime instead of inventing missing facts.
