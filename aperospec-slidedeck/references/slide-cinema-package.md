# Slide Cinema Package API Template

Use this template only when the input is a complete Narrative World Package (NWP) from `aperospec-cinema`.

## Input Gate

Before rendering, confirm the NWP contains:
- WORLD
- EMOTIONAL ENVIRONMENT
- SOMETHING IS COMING
- CORE CONFLICT
- EMOTIONAL CURVE
- IMMERSIVE EXPERIENCE
- VISUAL WORLD
- SCENE POTENTIALS

If these fields are missing, do not improvise. Ask for a valid NWP.

## Mapping Table

| NWP field | SCP rendering |
| --- | --- |
| WORLD | Opening Sequence |
| EMOTIONAL ENVIRONMENT | Atmosphere Layer |
| SOMETHING IS COMING | Narrative Tension Sequence |
| CORE CONFLICT | Conflict Sequence |
| EMOTIONAL CURVE | Slide Rhythm System |
| IMMERSIVE EXPERIENCE | Spatial Experience |
| VISUAL WORLD | Art Direction |
| SCENE POTENTIALS | Cinematic Scenes |

## Validation Checklist

Before finalizing, confirm:
- The input was an NWP.
- The output is an SCP.
- No world analysis was added.
- No new narrative was generated outside the NWP.
- Every slide is derived from an NWP field.
- Silent Slides are present.
- Scene comes before explanation.
- Emotion comes before information.
- The output avoids bullet-point PPT and corporate reporting.

## Forbidden Drift

Do not drift into:
- CWP analysis
- NWP generation
- business proposal
- enterprise report
- raw slide outline without shot logic
- dense bullet pages
- generic presentation style

When uncertain, render:
- WORLD into opening shots
- EMOTIONAL ENVIRONMENT into atmosphere
- SOMETHING IS COMING into tension
- CORE CONFLICT into emotional scenes
- EMOTIONAL CURVE into rhythm
- IMMERSIVE EXPERIENCE into spatial movement
- VISUAL WORLD into art direction
- SCENE POTENTIALS into storyboard moments
