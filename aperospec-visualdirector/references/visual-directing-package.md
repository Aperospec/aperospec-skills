# Visual Directing Package Template

Use this template only when the input is a complete Concept Deck Package (CDP) from `aperospec-conceptdeck`.

## Input Gate

Confirm the SBP contains:
- Slide Sequence
- Silent Slides
- Emotional Peaks
- Transition Slides
- Narrative Rhythm
- Scene Progression

If fields are missing, ask for a valid CDP from `aperospec-conceptdeck`.

## Required Output

```markdown
# Visual Directing Package (VDP)

## INPUT SOURCE

Storyboard Package:
[briefly name the concept deck]

## 1. SLIDE COMPOSITION

For each page:

### Slide [number]

Composition Type:
[Fullscreen / Split Layout / Cinematic Crop / Minimal Frame / Black Frame / Floating Composition]

Negative Space Ratio:
[high / medium-high / medium / low. Default to high unless the concept deck requires pressure.]

Text Density:
[none / one sentence / very low / low. Bullet points are forbidden.]

Focus Point:
[the first visual focus the audience notices]

Narrative Space:
[how the viewer enters the page rather than reads it]

## 2. TYPOGRAPHY DIRECTION

Overall typography principle:
[treat type as cinematic subtitles, not PPT text]

For each page:
- Amount of text:
- Sentence style:
- Alignment:
- Breathing:
- Emotional function:

Typography must avoid:
- dense text
- explanatory paragraphs
- bullet points
- information-first hierarchy

## 3. IMAGE DIRECTION

For each page:

Lens:
[35mm / 50mm / Wide Lens / Close-up / Long Shot / other]

Lighting:
[Cold Blue / Soft Natural / High Contrast / Screen Glow / Dark Ambient / other]

Atmosphere:
[Psychological Pressure / Isolation / Documentary Reality / Silent Anxiety / Emotional Distance / other]

Texture:
[Film Grain / Blur Reflection / Digital Noise / Soft Fog / Matte Surface / other]

Camera Feeling:
[Intimate / Distant / Surveillance / Human POV / other]

Image Role:
[how the image leads the slide before text appears]

## 4. VISUAL RHYTHM

Black frame pages:
[which pages are black frames and why]

Still pages:
[which pages should feel still]

Emotional explosion pages:
[which pages create visual impact]

Minimal pages:
[which pages use extreme restraint]

High-pressure pages:
[which pages increase psychological pressure]

One-sentence pages:
[which pages use only one line]

No-text pages:
[which pages use image or silence only]

Rhythm principle:
[how the sequence feels like cinema, not presentation]

## 5. CINEMATIC PROMPT

For each page:

```text
Environment: [specific environment]
Lighting: [lighting]
Lens: [lens]
Composition: [composition and framing]
Emotional Tone: [emotion]
Texture: [grain / blur / noise / fog / surface]
Cinematic Atmosphere: [overall atmosphere]
Prompt: [single integrated cinematic image prompt]
```

## 6. RENDERING NOTES

Image-led rule:
[how the image dominates the page]

Text restraint:
[how little text is allowed]

Silence rule:
[where black / empty / one-sentence silence appears]

Forbidden:
- corporate PPT
- document-style layout
- bullet points
- Canva style
- side-by-side image/text template
- information presentation style
```

## Validation Checklist

Before finalizing, confirm:
- Output is VDP, not SBP.
- No world analysis appears.
- No Narrative or Storyboard is rewritten.
- Every page has Composition Type, Negative Space Ratio, Text Density, and Focus Point.
- Every page has Lens, Lighting, Atmosphere, Texture, and Camera Feeling.
- Every page has a Cinematic Prompt.
- Slides are Image-led, not Text-led.
- Typography behaves like cinematic subtitles.
