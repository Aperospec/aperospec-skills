# Visual Directing Package Template

Use this template only when the input is a complete Storyboard Package (SBP).

## Input Gate

Confirm the SBP contains:
- Slide Sequence
- Silent Slides
- Emotional Peaks
- Transition Slides
- Narrative Rhythm
- Scene Progression

If fields are missing, ask for a valid SBP from `aperospec-storyboard`.

## Required Output

```markdown
# Visual Directing Package (VDP)

## INPUT SOURCE

Storyboard Package:
[briefly name the storyboard]

## 1. SLIDE COMPOSITION

For each page:

### Slide [number]
Composition:
[full-screen / split / black frame / image-led / one-line page]

Framing:
[where subject, title, negative space, and visual weight sit]

Black frame ratio:
[none / partial / full]

Visual hierarchy:
[image first / single sentence / insert detail]

## 2. TYPOGRAPHY SYSTEM

Overall type behavior:
[large / sparse / low density / one sentence / title as composition]

For each page:
- Font size:
- Density:
- Alignment:
- Breathing:
- Minimalism:

## 3. IMAGE DIRECTION

For each page:
- Camera distance:
- Lighting:
- Atmosphere:
- Grain:
- Blur:
- Texture:
- Photographic language:

## 4. VISUAL RHYTHM

Still pages:
[which slides hold still]

Black frames:
[which slides are black/silent]

One-sentence pages:
[which slides only carry one sentence]

Emotional impact pages:
[which slides create shock, pressure, or aftertaste]

## 5. AI IMAGE PROMPT

For each page:

```text
[cinematic image prompt with atmosphere, lighting, framing, lens, emotional tone, environment, cinematic texture]
```

## 6. RENDERING RULES

Image-led rule:
[how the image leads the page]

Text restraint:
[maximum text density]

Forbidden:
- bullet points
- corporate PPT
- long paragraph blocks
- document layout
```

## Validation Checklist

- Output is VDP, not SBP.
- Every page has an image direction.
- Every page has an AI image prompt.
- Slide design is image-led.
- No upstream analysis appears.
- Storyboard order is preserved.
