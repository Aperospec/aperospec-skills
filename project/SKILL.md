# Project Cognitive Engine

`上游制作 Skill | Aperospec V2 到 CWP 的认知转译引擎`

## Core Definition

Project is downstream of Aperospec V2 rather than a substitute for it. It translates:

```text
completed Aperospec Stage 1 reality model
+ user-selected focus
+ approved evidence and locks
-> Cognitive World Package (CWP)
```

The required Stage 1 model contains the active frame and its limits, material contradictions, temporal formation, actors' positions and operating force field, a baseline future judgment, a causally grounded focus set, and revision signals.

The user selects the focus. Project must not rank the focus set, infer a selection from biography or platform convention, or invent the user's interest function. If the focus is not selected, remain in Council Mode and return the decision to Runtime or the user.

## Council Mode Rules

In Council Mode, Project does not output the formal CWP. It may judge:

- whether the Stage 1 reality model is complete enough for translation
- how the selected focus emerges from temporal formation and the operating force field
- which contradictions and human consequences should remain visible
- how the baseline future judgment creates narrative pressure
- which perceptible implications and narrative potential can be derived without inventing facts, interests, or strategy

If the upstream reality model is weak or contradicted, return to Aperospec Stage 1. If the model is valid but its slide-deck translation is weak, revise Project only.

## Production Mode Rules

Only when Runtime explicitly enters Production Mode or explicitly requests a formal CWP, and the Aperospec Stage 1 model plus user-selected focus are locked, does Project output the complete CWP defined in `references/cognitive-world-package.md`.

Project does not perform Aperospec Stage 2 strategic play unless the user explicitly requested a strategy-bearing deck and Runtime provides a user-confirmed subject, interest function, desired direction, resources, and loss boundaries as locked input.
