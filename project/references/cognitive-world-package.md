# Cognitive World Package V2 Template

Use this template for formal `project` outputs. It translates a completed Aperospec V2 Stage 1 model and a user-selected focus into a narrative-ready cognitive artifact.

## Required Input Gate

```text
INPUT

TOPIC:
[topic / consequential situation]

APEROSPEC V2 STAGE 1 MODEL:
- active frame and limits
- material contradictions
- temporal formation
- actors' positions and operating force field
- baseline future judgment
- causally grounded focus set
- evidence status and revision signals

USER-SELECTED FOCUS:
[the focus explicitly selected by the user]
```

If the Stage 1 model is incomplete, return to Aperospec Stage 1. If the user has not selected a focus, stop before formal production and return the selection to the user. Do not infer or rank the focus on the user's behalf.

## Optional Stage 2 Lock

For a strategy-bearing deck only, Runtime may provide a user-confirmed Aperospec Stage 2 lock containing the represented subject, interest function, desired direction, resources, dependencies, time horizon, and loss boundaries. Preserve it exactly. Do not generate it inside Project.

## Validation Checklist

Before finalizing, confirm:

- The input contains a completed Aperospec V2 Stage 1 model.
- The selected focus was explicitly chosen by the user.
- Facts, reports, inferences, assumptions, and unknowns remain distinguishable.
- Public positions are not treated as complete causes.
- The temporal account includes mechanism, feedback, adaptation, and contingency.
- The baseline future is a strongest-warranted direction with confidence, signals, and redirection conditions.
- Deferred foci remain preserved and unranked.
- No subject interest, desired direction, or strategy was invented.
- The CWP contains no slide, page, typography, layout, screenplay, or visual-design execution.
- Narrative potential exists, but narrative execution remains with `cinema`.

## Forbidden Drift

Do not drift into:

- selecting or ranking the user's focus
- reducing the reality model to one hidden root cause
- treating motive lists as an operating force field
- scenario theater that avoids a baseline future judgment
- Aperospec Stage 2 strategy without user-confirmed interests and boundaries
- slide deck, scene, screenplay, visual world, business plan, or execution proposal

When uncertain, preserve the upstream structure:

- active frame before conclusion
- contradiction before coherence
- temporal formation before causal compression
- positions and mechanisms before motive claims
- baseline future before narrative anticipation
- user-selected focus before downstream translation
- revision signals before model closure
