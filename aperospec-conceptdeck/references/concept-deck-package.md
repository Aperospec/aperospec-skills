# Concept Deck Package (CDP) Template

Use this template only when the input is a complete Narrative World Package (NWP) from `aperospec-cinema`.

The goal of CDP is not only to describe deck feeling.

The goal is to hand a usable package to:

> `aperospec-visualdirector`

without requiring VisualDirector to invent missing page logic.

## Rules
- Every concept deck beat maps to the NWP.
- One concept per slide.
- One emotional state per slide.
- One atmosphere per slide.
- Forbidden: consecutive high-information slides.
- CDP must provide enough page-level content payload for VisualDirector to remain faithful without inventing copy.
- CDP may guide visual intent, but may not execute final poster composition.
