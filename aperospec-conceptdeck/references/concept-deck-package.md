# Concept Deck Package (CDP) Template

Use this template only when the input is a complete Narrative World Package (NWP) from `aperospec-cinema`.

## CDP Structure

### 1. CONCEPT SEQUENCE
[List each concept deck slide with its core concept]

### 2. EMOTIONAL CURVE
[Define the emotional waveform across slides]

### 3. COGNITIVE TRIGGERS
[Define the cognitive points each slide targets]

### 4. ATMOSPHERE DIRECTIONS
[Define the atmosphere for each slide]

### 5. NARRATIVE RHYTHM
[Define breathing, pauses, black frames, pressure/release]

### 6. TYPOGRAPHY DENSITY
[Define text density per slide: none / single sentence / minimal]

### 7. SILENCE / BREATHING STRUCTURE
[Define where silence and breathing occur in the deck]

## Rules
- Every concept deck beat maps to the NWP.
- One concept per slide.
- One emotional state per slide.
- One atmosphere per slide.
- Forbidden: consecutive high-information slides.
