# Aperospec Concept Narrative Engine

`概念驱动型沉浸式视觉叙事引擎`

## Core Definition

`aperospec-conceptdeck.skill` is not:
- a PPT generator
- a film storyboard tool

Its core task is:

> translating Narrative Universe into a concept-driven immersive Deck.

## Important Principle

This skill is not:

> "telling a story."

It is:

> "advancing cognition."

## What It Really Handles

The audience, on the next page:

> should feel something.

Not:

> the next shot happens.

## Difference from Storyboard

### Storyboard emphasizes:
- behavioral advancement
- shot logic
- scene continuity
- action flow

### Concept Narrative emphasizes:
- concept focus
- emotional focus
- atmosphere
- cognitive triggers
- emotional pauses
- negative space
- state transitions

## System Position

This skill sits after:

> `aperospec-cinema.skill`

It reads:

> Narrative World Package (NWP)

And generates:

> Concept Deck Package (CDP)

## Core Responsibility

This skill is responsible for:

### 1.
Decompose Narrative Universe into:

> Concept Sequence.

### 2.
Define, for each page, the real:

> Core Concept.

### 3.
Define, for each page, the emotional state:

> to be triggered.

### 4.
Define the Deck's:

> emotional advancement rhythm.

### 5.
Define the:

> breathing and pauses between pages.

## Core Philosophy

A truly advanced Deck is not:

> information arrangement.

It is:

> cognitive directing.

## Page Principle

- One page: only one concept.
- One page: only one core cognition.
- One page: only one emotional state.
- One page: only one atmosphere.

Forbidden: one page expressing multiple viewpoints simultaneously.

## Emotional Narrative Principle

Page advancement must feel like:

> an emotional waveform.

Not:

> an information list.

The Deck must include:
- emotional pauses
- black frames
- breathing
- pressure
- release
- emotional reversals
- cognitive impact

## Narrative Structure

The Deck must form:

> a concept advancement structure.

### Typical Flow

1. **Opening Atmosphere** — establish world state
2. **Cognitive Trigger** — trigger audience attention
3. **Emotional Pull** — begin emotional engagement
4. **Pressure Build-up** — build psychological pressure
5. **Emotional Peak** — form cognitive impact
6. **Silence** — give pause and negative space
7. **Reconstruction** — re-establish cognition and emotion
8. **Ending Statement** — ultimately form conceptual residue

## Typography Principle

Text is not:

> information.

It is:

> emotion.

### Typography Rules

- Default: extremely little text.
- One sentence is better than one paragraph.
- Negative space is better than explanation.
- Text must breathe.

Forbidden:
- bullet points
- document paragraphs
- dense text
- manual-style expression

## Atmosphere Principle

Pages must prioritize establishing:

> Atmosphere.

Atmosphere comes before:
- function
- mechanism
- execution logic

## Concept Construction Rules

Every page must include:

### 1. Core Concept
What this page truly expresses.

### 2. Emotional State
What state the audience should enter.

### 3. Cognitive Trigger
The cognitive point this page truly aims to strike.

### 4. Atmosphere Direction
What atmosphere this page should have.

### 5. Narrative Weight
What emotional weight this page carries in the overall Deck.

## Exhibition Proposal Narrative System

ConceptDeck is not:

> film storyboard.

Nor is it:

> a purely emotional concept poster.

It is:

> Narrative-driven Exhibition Proposal.

## Exhibition Proposal Core Principle

Every page must contain, at the same time:
- Narrative advancement
- information expression
- exhibit-item explanation
- educational meaning
- Atmosphere
- Concept Direction

## Exhibition Concept Unit Principle

Every page defaults to:

> one complete Concept Unit.

One page should, whenever possible, fully express:
- core viewpoint
- exhibit purpose
- educational meaning
- relationship to the theme
- Narrative
- Visual Direction

### Important Rule

Forbidden:

> splitting one complete cognitive unit excessively into multiple emotional pages.

## Exhibition Proposal Principle

ConceptDeck must always preserve:

> exhibition proposal logic.

Narrative:

> advances.

Information:

> explains.

Exhibit items:

> ground the proposal.

Atmosphere:

> creates emotional involvement.

All four must exist at the same time.

## Exhibition Information Density Rule

Pages must have:

> enough information density.

Forbidden: pages that only contain:
- title
- emotional sentence
- empty-shot concept

while lacking:

> actual exhibit-item content.

## Narrative Split Constraint

By default:

> one exhibition zone corresponds to one page.

Unless one of the following occurs:
- Chapter Transition
- Ending
- Cognitive Shock
- strong pause
- worldview switch

forbidden:

> further page splitting.

## Exhibition-first Principle

Cinematic feeling may only serve as:

> a rhythm support tool.

It must not override:

> exhibition information expression.

## Exhibition Proposal Ultimate Principle

ConceptDeck's final goal is not:

> "to feel like a movie."

It is:

> letting the client truly understand why this exhibition works.

## Slide Rhythm System

The Deck must form:

> a breathing rhythm.

Must allow:
- large areas of negative space
- black frames
- textless pages
- single-sentence pages
- atmosphere pages
- still pages

### Important Rule

Forbidden: consecutive high-information-density pages.

### Concept Density Rule

An advanced Deck is not:

> "more information is more advanced."

It is:

> "more focused concept is more advanced."

## Image Principle

Images are not:

> illustrations.

They are:

> emotional subjects.

Images must:

> dominate the page.

## Narrative Silence Principle

Allow certain pages to explain nothing.

Because true immersion often comes from:

> feeling.

Not:

> understanding.

## Client Pitch Principle

This skill defaults to serving:

> Pitch Mode.

Pitch Mode prioritizes output of:
- emotion
- concept
- atmosphere
- educational meaning
- narrative feeling

Not:
- execution logic
- technical structure
- program flow

## Production Difference

Execution layer belongs to:

> Production Pipeline.

Concept Deck belongs to:

> Client Narrative Layer.

## Director Rhythm System

The Deck is not:

> a collection of pages.

It is:

> an emotional directing process.

### Core Principle

A truly advanced Narrative Deck must have:

> rhythm variation.

Forbidden: the entire Deck maintaining one uniform page structure.

### Narrative Rhythm Principle

The Deck must form:

> an emotional waveform.

Not:

> template repetition.

### Emotional Wave Structure

The Deck must include:
- pressure
- pause
- negative space
- quietness
- eruption
- narrative descent
- emotional release
- cognitive shock

## Page Density System

Pages must form:

> information-density variation.

Forbidden: all pages carrying the same amount of information.

The Deck must include:
- pure Atmosphere pages: image only
- black-frame pages: one sentence only
- Narrative pages: cognitive explanation
- Cognitive Shock pages: large-type impact
- silent pages: no explanation
- high-information-density pages: used for world-building

## Layout Variation Rules

Forbidden: three consecutive pages using the same layout.

Typography:

> must not repeat in a fixed position.

Images:

> must not use a uniform composition.

Each chapter must have its own:

> rhythm structure.

## Opening Rhythm

The Opening must not directly enter content.

The Opening must first establish:
- world state
- emotional tone
- Narrative Universe
- audience psychological position

## Transition Rhythm

Transitions must form:

> narrative descent.

Transitions must make the audience feel:

> "we are entering a deeper structure."

## Silence Principle

Advanced Decks must allow:

> quietness.

Some pages may explain nothing.

Because immersion often comes from:

> emotional pauses.

## Cognitive Explanation Principle

Minimalism is not:

> emptiness.

Besides concept, each page must contain:

> narrative advancement.

Narrative must explain:
- why the Deck enters the next stage
- why the emotion begins to change
- why danger begins to approach
- why the audience should care about this point

## Narrative Weight Principle

Every page must define:

> emotional weight.

Some pages must be extremely light.

Some pages must be extremely heavy.

Forbidden: all pages having the same emotional weight.

## Visual Rhythm Principle

Visuals must form:

> breathing.

The Deck must include:
- Fullscreen Image
- Tiny Typography
- huge titles
- full black pages
- negative-space pages
- text-only pages
- high-pressure pages
- Narrative pages

## Ultimate Rhythm Principle

A truly advanced Deck is not:

> "laying content out."

It is:

> "directing the audience's emotional progression."

## Information Density Control System

An advanced Deck is not:

> "more page splitting means more sophistication."

It is:

> "every page carries complete cognitive value."

### Core Principle

Pages must center on:

> Concept Unit.

One page should default to:

> one complete cognitive unit.

Forbidden:

> splitting one complete Concept excessively into multiple emotional fragment pages.

## Concept Unit Rules

One page should, whenever possible, contain:
- core viewpoint
- Narrative advancement
- educational meaning
- emotional direction
- Atmosphere
- Visual Narrative

These should not be unnecessarily split across multiple pages.

## Page Splitting Constraint

Forbidden:
- adding meaningless page count for "cinematic feeling"
- forcing one complete expression to split into multiple pause pages
- over-slowing the Narrative

## Information Density Principle

Pages must have:

> enough cognitive density.

Every page must genuinely advance:

> Narrative.

Not only express:

> a single emotional fragment.

## High-Density Narrative Rule

Some pages may carry, at the same time:
- title
- concept explanation
- educational meaning
- Atmosphere
- image
- Narrative advancement

Because a truly advanced Pitch is not:

> "breaking content apart."

It is:

> "high-density precise expression."

## Splitting Permission Rules

Independent page splitting is allowed only for:
- black frame
- Ending
- Cognitive Shock
- emotional eruption
- Narrative turn
- worldview switch
- strong pause

In all other situations:

> prefer merged expression by default.

## Pitch Efficiency Principle

Pitch Decks must preserve:

> Narrative efficiency.

Forbidden: making the audience feel:
- "why is this not finished yet?"
- "the information is advancing too slowly"
- "there are too many pages"

## Ultimate Density Principle

A truly advanced Deck is not:

> "slow like a movie."

It is:

> "precise like a director."

## Output Protocol

This skill must always output:

> Concept Deck Package (CDP)

### CDP must include:

1. Concept Sequence
2. Emotional Curve
3. Cognitive Triggers
4. Atmosphere Directions
5. Narrative Rhythm
6. Typography Density
7. Silence / Breathing Structure
8. Exhibition Proposal Narrative
9. Exhibit-item Explanation Logic
10. Information Density Control
11. Concept Unit Integrity
12. Page Splitting Logic

## Ultimate Principle

A truly advanced Deck is not:

> "showing content."

It is:

> "letting the audience enter a state."
