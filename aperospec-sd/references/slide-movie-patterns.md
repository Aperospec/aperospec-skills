# Aperospec Slide Movie Patterns

Use these templates only after a Narrative World Package exists.

## Input Gate

Before producing slides, confirm the input contains:
- WORLD
- CORE DRIVING FORCE
- CORE CONFLICT
- EMOTIONAL CURVE
- FUTURE VISION
- COGNITIVE TRIGGERS
- IMMERSIVE EXPERIENCE
- VISUAL WORLD
- STRUCTURAL ELEMENTS

If these are missing, do not produce a deck directly. Ask for or construct a Narrative World Package first.

## STEP 1: Screenplay Generation

```markdown
# Screenplay

## Opening
[How the world opens. The audience enters before they understand.]

## Conflict
[What emotional or structural conflict begins to appear.]

## Emotional Escalation
[How pressure rises across the deck.]

## Transition
[Where the rhythm turns, pauses, or changes state.]

## Future Vision
[What elevated future image remains at the end.]
```

## STEP 2: Visual Script Generation

```markdown
# Visual Script

## Visual Law
[The core visual law of this Slide Movie.]

## Light
[Light direction, contrast, darkness, cold/warm tone.]

## Atmosphere
[Air density, silence, pressure, texture, sound implication.]

## Camera
[Wide / static / tracking / close-up / insert logic.]

## Typography Density
[silent / very low / low / insert-only medium.]

## Rhythm
Opening -> Silent -> Emotional -> Insert -> Transition -> Future Vision
```

## STEP 3: Storyboard Deck Generation

```markdown
# Storyboard Deck

## Slide [number]: [title as image]

Type:
[Opening / Silent / Emotional / Insert / Transition / Future Vision]

Shot:
[Establishing Shot / Wide Shot / Medium Shot / Close-up / Insert Shot / Silent Shot / Transition Shot]

Function:
[What this shot does emotionally and narratively.]

Scene:
[What the audience sees before they understand.]

Text:
[One line or one short paragraph. No dense explanation.]

Image:
[Full-bleed cinematic image direction with time, civilization, space, human traces, and emotional tension.]

Motion:
[Optional movement, reveal, pause, fade, cut, or transition.]

Silence:
[Where the slide breathes.]
```

## Silent Slide Template

```markdown
## Slide [number]: [one sentence]

Type:
Silent

Shot:
Silent Shot

Scene:
[Black frame / empty space / one image / one human trace.]

Text:
[One sentence only.]

Function:
[Pause / pressure accumulation / rhythm reset / emotional echo.]
```

## Insert Slide Template

```markdown
## Slide [number]: [credible detail]

Type:
Insert

Shot:
Insert Shot

Scene:
[A document, interface, data fragment, object, sensor, screen, hand, trace, or evidence.]

Text:
[Only the minimum information needed for credibility.]

Function:
[Reality information enters without breaking the film.]
```

## Checks

Before finalizing, check:
- Did the deck start from the world instead of information?
- Does every slide have one visual core?
- Does every slide have a shot type?
- Are Silent Slides present?
- Does data appear only after scene and emotion?
- Does the deck avoid corporate reporting language?
- Does it feel like a Slide Movie rather than a presentation?
